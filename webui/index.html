⚠ 权限不足:当前为 Safe 模式

检测/修复按钮需要 Full access 权限才会被管理器放行,按下面步骤打开:
  1. 返回模块列表
  2. 点 Berry-FCM 卡片上的 ⚙ 调节图标
  3. Access mode 选 Full access
  4. 顺手打开 Allow background actions(开机自愈需要)
  5. 回到本页,点下方「重新检测权限」
等待期间,下方状态区会显示最近一次检测的只读报告。

WebUI 桥不可用(管理器缺陷 · 非本模块问题)

本管理器的 release 版在打包时把网页桥的方法全部剥离了(R8 混淆缺 keep 规则),所有模块的 WebUI 都执行不了命令 —— debug 版管理器正常。
✅ 模块功能不受影响:请回模块列表点 「操作」(Action)按钮执行检测/修复(原生路径);开机自愈照常。
本页已转为只读模式:显示最近一次检测报告(点过「操作」或开机自愈后,回来点下方「刷新报告」)。

操作

修复 = 解除 stopped 标记(cmd package unstop)+ 三连 GCM 心跳;监视 = 90 秒内每 15 秒自动巡检并修复。Action 按钮同「一键修复」。

守护目标

GMS 为核心目标不可移除。Telegram 等 IM 被 vivo 强杀后同样收不到推送,加进来一起守护。

vivo 快捷入口

OriginOS 常悄悄关掉 GMS 通知渠道/自启动,这两个入口请定期检查(与原版 App 引导一致)。
